# 三国象棋 · 设计方案（初稿）

> 2026-10-03 已用 AI 自对弈 1000 局测试，结论和修订建议见 [测试报告.md](测试报告.md)。已确认的修正：马不能绕过中原三角跳。

目标：尽量保留中国象棋的走法和手感，让三个人同时对弈，并且三方地位对称、不容易出现"两家打一家"或"坐山观虎斗"。

## 一、推荐方案：三叶六边形棋盘（"鼎立盘"）

### 1. 棋盘怎么来的

把普通象棋的"半边棋盘"（9 路 × 5 行，含九宫）沿中路竖着劈成左右两翼，每翼 5×5 个交叉点（中路共用）。三个国家的半边棋盘围成一个六边形：

- **底线**：每国占六边形的一条边（魏在北，吴在东南，蜀在西南）。
- **两条前线**：我的**左翼**隔一条河正对左邻国的**右翼**，我的**右翼**隔河正对右邻国的**左翼**。三条河分别叫汉中（魏蜀）、长江（魏吴）、夷陵（蜀吴）。
- **中原**：三国的中路（帅所在的第 5 路）在棋盘中心汇成一个小三角。三角的三个角就是三国中路的河口，彼此相邻。

全盘 135 个点（每国 45 个，和普通象棋的半盘完全一样），没有新增空地。

**为什么好**：每条前线的纵深和普通象棋一样（己方 5 行 + 河 + 对方 5 行），所以开局、炮马的距离感、过河兵的节奏都和原版一致；每个人天然要两线作战，谁也没法只盯着一家打。

### 2. 棋子与走法（只改必须改的）

开局摆法和原版完全一样，每方 16 子。

| 棋子 | 规则 |
|---|---|
| 帅、仕 | 不变，只在自己九宫里走。 |
| 相（象） | 不变，不能过河，只在自家 45 个点内活动。 |
| 车 | 走直线不变。线在两翼交界处会"拐个弯"，但仍算同一条直线。**中原规则**：车沿己方中路冲到河口后，可以选择进入任一邻国的中路继续直行。 |
| 炮 | 同车的线路，翻山规则不变。 |
| 马 | "一步直 + 一步斜"、蹩马腿都不变。棋盘每一格仍是四边形，只有中央那个三角不算格子，马不能斜穿它。 |
| 兵 | 过河前只能向前。从左翼过河就进入左邻国，从右翼过河进入右邻国；过河后"前"指向那个国家的底线，也可以横走。中路兵冲到河口后，自己选择进入哪一家。 |
| 飞将 | 保留：两个帅之间若中路（经中原）无子相隔，不能"照面"。这样中路的争夺会很激烈，三家都要守中原。 |

### 3. 行棋顺序

按顺时针轮流：**魏 → 吴 → 蜀**。每局轮换先手。先手优势在象棋里本来就小，三人局里会更小，因为先手最先暴露在两家面前。

### 4. 胜负：吃帅制 + 吞并

**判定方式**：用"吃掉将帅"判负，不用"将死"。三人局里，你被一家将军后，另一家可能先行把局面改了，"将死"很难判断。所以不强制应将，帅被吃掉才出局，没解将就要自己承担风险。

**被吃帅的一方怎么处理**：推荐**吞并**——出局一方剩下的车、马、炮、兵原地改成吃帅者的颜色，归他指挥（"降将"）；仕、象被移除，因为它们出不了那个已经空了的九宫。

为什么选吞并、不选"直接移除"：

- 如果直接移除，最划算的打法是**坐山观虎斗**：等另外两家拼到两败俱伤再出手。
- 吞并以后，谁先吃掉一个帅，兵力立刻接近翻倍。旁观的第三家必须出手干预，绝不能让任何一家轻易吃帅。这个"三国均势"是游戏自己会形成的，不需要额外规则。

**最后剩下的一家获胜**。如果想玩快一点，可以用"首帅即终局"：第一个帅被吃时游戏结束，按子力分（车 9、炮 4.5、马 4、仕象 2、兵过河 2 / 未过河 1）加上"吃帅奖励 10 分"排名。

### 5. 防围攻、防"拥立"的平衡设计

1. **两线结构**：每家同时面对两个对手，围攻一家时，围攻者自己的另一条线也是空的。
2. **吞并**：见上，主动进攻有回报，看戏不划算。
3. **长将、长捉**：沿用原版规则，判给"长"的那一方，不允许一家无限纠缠另一家。
4. **结盟（房规二选一）**：
   - 竞技模式：禁止场外交流；
   - 演义模式：允许口头结盟和背盟，但没有任何规则约束（"孙刘联盟"随时会翻脸，这才是三国味）。
5. **和棋**：三方同意，或者 N 回合没有吃子就按上面的子力分排名。

### 6. 三国特色（可选，等基础规则测平衡后再加）

在基础规则里三国完全对称。想加一点个性，可以每国给一个"锦囊"，**每局限用一次**，用在自己回合的那一步棋上：

| 国 | 锦囊 | 效果 |
|---|---|---|
| 魏 | 虎豹骑 | 本步一个马无视蹩马腿。 |
| 蜀 | 八阵图 | 本步走完后，指定己方一个子（非帅），到你下回合之前不能被吃。 |
| 吴 | 火烧连营 | 本步一个炮可以隔两个子打。 |

视觉主题：魏蓝、蜀红、吴绿；帅分别写"魏/蜀/吴"，也可以换成曹操/刘备/孙权的头像。

## 二、其他方案（比较后没有选）

**B. 赤壁模式（2 打 1，用标准棋盘）**
魏单独一方；蜀、吴共用另一方，蜀管左边 4 路的子，吴管右边 4 路的子，帅大家一起守。走子顺序是魏→蜀→魏→吴。
优点：零新规则，现有棋盘就能玩，很适合聚会。
缺点：不是真正的三方混战，结盟是写死的。可以当成附加模式。

**C. 中原大盘（三个半盘 + 中间一大块空地）**
三家的半盘对着中间一块六边形空地，空地中心有个"许昌"之类的目标点。
缺点：开局要走很久才能接触，子力不够铺满空地，需要加新棋子，离原版太远。

**D. 改成六边形格子**
马、象、炮都要重新定义，基本就不是象棋了。

**结论**：A 是对原版改动最少、三方完全对称、天然两线作战的方案，推荐作为起点。B 可以作为额外的轻量模式。

## 三、还需要实测的问题

- 中原三角会不会让中路攻势太快（车/炮可以选择两个方向）？必要时可以规定"车炮过中原只能直行到其中一家，且一步棋内不能拐两次"。
- 吞并会不会导致第一个吃帅的人必胜？如果会，改成"只吞并车马炮各一个，其余移除"。
- 先手优势要靠实战统计。
